# Wenran Liu's Homepage

Personal academic homepage for [Wenran Liu](https://liuwenran.github.io/).

The site is built with Jekyll and is visually based on the open-source academic
homepage used by [Xiaoteng Ma](https://xtma.github.io/). The underlying theme is
derived from Minimal Mistakes and the academicpages-style template under the MIT
License.

## Local preview

```bash
bundle install
bundle exec jekyll serve
```

Then open `http://localhost:4000`.
